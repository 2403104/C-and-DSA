typename = decltype(begin(declval<Iterables>()))
-----------------------------------------------
Purpose: Checks if begin(container) is valid.

How it works:
- declval<Iterables>() produces a fake object of type Iterables (without constructing it).
- begin(...) tries to call the begin() function (either global or member).
- decltype(...) captures the return type.

Effect:
This makes the template only participate in overload resolution if Iterables is iterable.

typename = typename enable_if<!is_same<Iterables, string>::value>::type
------------------------------------------------------------------------
Purpose: Excludes std::string from matching.

Explanation:
- enable_if enables this template only if Iterables is not std::string.
- is_same<Iterables, string>::value is true if Iterables is string,
  so we negate it (!) to allow all types except string.
